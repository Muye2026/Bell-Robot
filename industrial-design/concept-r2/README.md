# Bell Robot 挂屏外观概念 R2

这轮是 `concept-r1` 之后的风格扩展版。
目标不是继续细抠同一种工具配件，而是把方向明确拉开成两条线：

- 轻薄科技感
- 电子宠物感的友好桌面设备

两条线都继续遵守同样的产品边界：它首先仍然是一个挂在显示器顶部的设备，不是桌面摆件，也不是玩具。

## 本轮共通约束

- 继续优先适配 `24/27` 寸外接显示器。
- 主形态仍然是顶部挂钩夹持，不引入折叠底座。
- 摄像头继续居中或接近居中，并保持轻微下俯。
- `0.96` 寸 OLED 继续保留在正面左侧直窗位置。
- 右侧肩位或右端面继续保留按钮区，但按双按键预留：`GPIO1` 重置/重校准，`GPIO2` 采样。
- 蜂鸣器尽量不占正面核心视觉区。

## 四个方向怎么区分

### Tech-1

- 关键词：超薄、精密、低存在感、工具属性最强。
- 特征：长条感最明显，边线更硬，体量最克制。
- 优势：最像成熟显示器配件，后续进 3D 比较直接。
- 风险：如果后续真实器件尺寸吃紧，容易从“薄”掉到“不可信”。

### Tech-2

- 关键词：悬浮、轻量、精致、现代消费电子。
- 特征：正面更像细边框电子设备，黑色镜头带更强，气质比 Tech-1 更轻。
- 优势：更高级、更轻巧，桌面融合感好。
- 风险：如果结构支撑没处理好，容易看起来只是“漂亮”，不够稳。

### Pet-1

- 关键词：温和、圆润、友好、电子陪伴感更明显。
- 特征：整体更像被柔和包裹过的设备，弱脸感最明显，但仍没有拟物。
- 优势：有记忆点，陪伴感更强，容易和普通监视器配件拉开。
- 风险：如果再往前推一步，容易跨到玩具感。

### Pet-2

- 关键词：克制、温和、成熟电子伙伴。
- 特征：比 Pet-1 更收敛，仍有友好感，但更接近真正可售卖的桌面硬件。
- 优势：在“陪伴感”和“工具属性”之间平衡最好。
- 风险：如果后续再收得太多，可能又会退回普通工具型设备。

## 这一轮怎么评审

- 看它是不是仍然一眼能认成挂屏设备。
- 看摄像头是否像真正会工作的视觉器件，而不是装饰。
- 看 OLED 是否还能在看主屏时被余光快速读取。
- 看四个方向是不是风格真的拉开了，而不只是换圆角。
- 看哪一条值得进入下一步 3D，而不是只停留在概念气质。

## 当前建议

- 如果你优先考虑尽快进入结构建模，优先从 `Tech-1` 或 `Tech-2` 里选。
- 如果你更重视产品记忆点、桌面陪伴感和品牌个性，优先看 `Pet-2`，再看 `Pet-1`。
- 从这轮结果看，`Pet-2` 是目前“电子宠物感”里最克制、最接近量产产品气质的方向。

## 使用边界

- 这些图仍然只是概念板，不是尺寸图，也不是装配图。
- 内部布局图只表达模块分区，不代表最终精确堆叠。
- 下一步如果选定单一方案，再进入 3D 时应当补：屏幕厚度适配区间、挂钩受力、镜头俯角、OLED 开窗和主板包络。
