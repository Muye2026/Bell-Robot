## 本轮统一约束

- 优先适配 `24/27` 寸外接显示器，笔记本只做兼容表达。
- 结构基线是顶部挂钩夹持，不引入复杂折叠机构。
- 摄像头视角稳定优先，镜头位于正中或接近正中，前向略下俯。
- `0.96` 寸 OLED 保持正面直窗，方便看电脑时余光读数。
- 单按键保持在右侧肩位附近，蜂鸣器尽量转移到底部或后侧。

## 方案判断

### 方案 A

- 关键词：横向条形体、最像成熟显示器配件、平衡度最好。
- 优点：整体最稳，OLED 与摄像头分区清晰，后续做成一体壳也最顺。
- 风险：长度更长，对内部堆叠和挂钩强度要求更高。
- 建议：如果你希望第一版尽快进入 3D，这个方案最适合作为主线。

### 方案 B

- 关键词：中置主舱、摄像头存在感最强、中心更稳。
- 优点：最强调“监看核心”，镜头可信度高，视觉重心集中。
- 风险：中间主舱更厚，容易显得偏重，挂屏结构需要更认真处理重心。
- 建议：如果你后续更想强化摄像头和智能硬件感，可以把它作为第二优先。

### 方案 C

- 关键词：轻夹片体、更薄、更收敛、对笔记本更友好。
- 优点：体量最克制，最容易融入桌面环境，兼容薄屏思路最好。
- 风险：稳定感弱于 A/B，内部空间更紧，对真实模组尺寸更敏感。
- 建议：如果你后面决定兼顾笔记本，这个方向值得继续细化。

## 评审时重点看什么

- 挂在显示器上是否看起来真的稳。
- 摄像头是否像真正能工作，而不是装饰。
- OLED 是否在主屏工作时能被余光快速捕捉。
- 整体是否像成品，而不是“开发板加外壳”。

## 使用边界

- 图中内部布局只表达模块分区，不代表精确尺寸和最终叠层。
- 图中的 OLED 字样、孔位、开缝、倒角都是概念级表达，进入 3D 时需要按真实器件重新校核。
- 下一步应当在你选定主方案后，再补屏幕厚度区间、摄像头俯角、OLED 开窗和主板包络。
