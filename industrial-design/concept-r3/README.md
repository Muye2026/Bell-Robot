# Bell Robot Tech1 棱角化对称外观 R3

本轮在 `Tech1` 现有概念基础上重新收敛外观方向：主体更棱角分明，左右端部外轮廓更对称，同时继续遵守 `tech1-structure-r1` 里的挂屏结构和内部堆叠约束。

## 文件

- `01-tech1-angular-a.png`：接近原 Tech1 的硬朗精修版。
- `02-tech1-angular-b.png`：强化中心黑色功能岛，并用右侧暗色服务窗平衡左侧 OLED。
- `03-tech1-angular-c.png`：更工程化的折面版本，侧视和背部支撑表达更清楚。

## 共同约束

- 主体仍按细长条形主机处理，参考包络为 `130 x 34 x 17-19mm`。
- 背部支撑延续挂屏灯逻辑：前小支点、后支撑臂、软垫防滑，不采用弹簧强夹结构。
- 后支撑臂参考后伸量为 `32-38mm`，侧视图中必须能读出承重关系。
- 内部布局保持左 OLED、中置摄像头、右侧开发板/USB 服务区、右下层扬声器或蜂鸣器。
- 左右对称优先指外壳端部、斜切面、边线、厚度和视觉重量；内部器件不强行对称。

## 变体判断

### A：原方案硬朗化

优点是最接近 `concept-r2` 的 Tech1 方向，改动幅度小，比较适合作为保守迭代。端部斜切和直线高光让主体比上一轮圆润版本更硬朗。

风险是结构说明感相对弱，如果直接进入建模，还需要单独补一版后支撑细节。

### B：功能区平衡版

优点是正面秩序更完整：左 OLED、中心摄像头和右服务区之间的视觉重量更均衡，比较符合“左右两侧要对称”的外观诉求。

风险是右侧服务窗需要在 3D 里进一步拆分 USB、按键和出声孔，避免真实结构过于拥挤。

### C：工程折面版

优点是最适合进入 3D 草模。它对折面、端盖、后支撑臂和内部堆叠的表达更明确，也更容易按结构原理拆成主壳、端盖、支撑臂、软垫和内部支架。

风险是消费电子精致感略弱于 B，后续需要通过材质、倒角半径和接缝处理补回来。

## 推荐

建议以 `03-tech1-angular-c.png` 作为 3D 草模结构基准，以 `02-tech1-angular-b.png` 作为正面外观秩序参考。也就是先按 C 把主体、端盖和后支撑做出来，再吸收 B 的黑色功能区比例和右侧服务窗处理。
