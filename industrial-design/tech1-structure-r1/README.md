# Bell Robot Tech1 结构细化 R1

这组文件把 `Tech1` 从概念风格推进到可进入 3D 草模的结构参考层。
目标不是直接给出最终可生产结构，而是先把 `挂屏逻辑`、`平面堆叠` 和 `关键尺寸约束` 固定下来，避免后续建模时反复改大方向。

## 结构基线

- 采用显示屏挂灯常见的 `前小支点 + 后配重支撑臂 + 软垫防滑` 逻辑。
- 不做强夹力弹簧夹；主要依靠重心落在屏幕上沿后方来稳定。
- 兼容厚度目标：
  - 主目标：`8-35mm`
  - 超薄挂靠：`3-8mm`，需要附加硅胶垫，不追求高夹持力。
- 前主机条形体先按 `130 x 34 x 17-19mm` 处理。
- 后支撑臂总后伸量先按 `32-38mm` 处理。
- 摄像头前向微下俯 `6-10°`。
- 双 USB 全外露，优先保证供电、烧录和调试效率。

## 平面堆叠摘要

- 坐标原点：主机内腔左上角。
- 内腔尺寸：`124 x 31mm`。
- OLED 模组：`28 x 28mm`，建议区 `X=4~32, Y=1.5~29.5`。
- OLED 可视区：`28 x 15mm`，建议外壳开窗 `29 x 16mm`。
- 摄像头结构包络：`14 x 14mm`，建议区 `X=44~58, Y=8.5~22.5`。
- 开发板：`57 x 28mm`，建议区 `X=60~117, Y=1.5~29.5`。
- 扬声器/蜂鸣器：`Ø12mm`，建议中心 `X=108, Y=15.5`，允许与主板顶视图重叠，但必须分 Z 层。
- 按键：按 `6 x 6mm` 轻触开关处理，建议区 `X=118~124, Y=12.5~18.5`。

## Z 向分层

- 前层：OLED 视窗、镜头开孔、按键帽。
- 中层：OLED 模组、摄像头支架、开发板主体。
- 下层：扬声器/蜂鸣器、后支撑臂连接件、USB 走线余量。

## 当前判断

- 这版布局能保持 `Tech1` 的极简条形体，不需要把所有器件在同一平面完全摊开。
- 真正决定后续是否还能继续“薄”的关键，不是 OLED 或镜头，而是：
  - 右端双 USB 服务区
  - 主板与扬声器的上下分层
  - 中部挂点和后支撑臂的连接厚度
- 如果你下一步确认要进 3D，建议先做两件事：
  - 用 `1:1` 打印图切纸板，快速验证正面秩序和端口冲突。
  - 量一次你手上开发板的真实 USB 外壳、插头占用和摄像头模组厚度，把 Z 向再收紧。

## 注意

- 这组文件仍然是结构参考，不是最终装配图。
- 若后续改成自定义 PCB，这套平面分区仍可保留，但主板区会明显更松。
